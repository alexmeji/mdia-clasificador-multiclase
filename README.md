# Multi-Class Classifier — Palmer Penguins

Final project for the Applied Machine Learning course, Master's in Artificial
Intelligence, Universidad Galileo.

## Overview

A multi-class classification study on the Palmer Penguins dataset (3 species:
Adelie, Chinstrap, Gentoo). Three model families are trained, compared and combined:

- **Random Forest**
- **XGBoost**
- **Neural Network (Keras)**

Each family is explored across five configurations (15 experiments total), every run
is logged to a persistent CSV, and the best model of each family is combined into a
bootstrap majority-voting ensemble.

## Methodology

- Missing values removed; categorical features (`island`, `sex`) one-hot encoded.
- Single stratified 80/20 train-test split with a fixed `random_state` (**no
  cross-validation**).
- Features standardized (fit on train only) for the neural network.
- Eight metrics logged per experiment: accuracy, precision, recall and F1, on both
  train and test (macro-averaged).
- Best model per family selected by highest test F1.
- Feature importance compared between Random Forest and XGBoost.
- Bootstrap majority-voting ensemble with an explicit tie-breaking rule.
- Final train-vs-test comparison with an underfitting / overfitting / good-fit
  diagnosis.

## How to run

The notebook runs end-to-end in Google Colab with no local setup. Alternatively,
run locally:

```bash
pip install -r requirements.txt
jupyter notebook clasificador_multiclase.ipynb
```

Run the cells in order. The experiment log is reset at the start and rebuilt as the
experiments execute.

## Results summary

All three families reach high test F1 at their best configuration; underfitting is
observed only in the deliberately constrained runs. The bootstrap ensemble matches
the strongest individual models. Full analysis and conclusions are in the notebook.
